# Structural patterns

Contextual signals:
- repeated paragraph templates;
- uniform sentence/paragraph lengths;
- topic -> explanation -> mini-conclusion repeated mechanically;
- forced triads;
- repetitive contrast structures;
- one-line closers that restate the prior paragraph;
- listification where prose would be natural;
- excessive symmetry.

Do not edit a structure merely because it is regular. Genre and author samples override the heuristic.
