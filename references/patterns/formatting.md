# Padrões de formatação

Formatação só é um sinal quando parece aplicada por hábito do gerador, não pela necessidade do documento.

## Bold labels

Padrão:
- **Contexto:** ...
- **Problema:** ...
- **Solução:** ...

Pode ser ótimo em documentação. Vira problema quando todo parágrafo é convertido em label + definição sem necessidade.

## Headings excessivos

Muitos títulos para blocos minúsculos fragmentam textos que deveriam fluir como prosa.

## Title Case

Em PT-BR, capitalização de headings deve respeitar estilo do projeto/documento. Não converter mecanicamente para Title Case inglês.

## Emoji decoration

Emoji em todos os headings/bullets pode produzir tom artificial se o autor/canal não sustenta.

## Travessão

Travessão não é evidência de IA. Observar:
- frequência;
- função;
- posição;
- gênero;
- amostra do autor.

## Listas

Usar lista quando:
- itens são paralelos;
- leitura escaneável importa;
- ordem/enumeração é real.

Evitar lista quando:
- relações causais precisam de prosa;
- cada bullet vira um miniensaio idêntico;
- o texto foi "listificado" apenas para parecer organizado.

## Preservação

Não alterar:
- Markdown necessário;
- tabelas úteis;
- blocos de código;
- estrutura obrigatória de template;
- links e anchors;
- headings usados por navegação.
