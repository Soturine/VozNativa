# Arquivos do quickstart

Textos curtos escritos para a documentação do VozNativa (MIT, sem conteúdo de terceiros), usados pelos comandos do README principal e testados por `evals/test_readme.py`.

| Arquivo | Para quê |
|---|---|
| `original.txt` | texto com fórmulas ("É importante destacar que", "Vale ressaltar que") e valores protegidos |
| `candidata-boa.txt` | reescrita que preserva data, valor, negação e a ação (enviar → encaminhar) |
| `candidata-ruim.txt` | reescrita que remove a negação |
| `candidata-perde-acao.txt` | reescrita que mantém valores e negação mas troca a ação por um verbo leve ("vai até") |
| `email.txt` | e-mail natural que não precisa de mudança |
| `erros.txt` | palavra repetida e dia da semana que não bate com a data |
| `documento-longo.md` | documento com seções, código e tabela para a reescrita por unidades |
