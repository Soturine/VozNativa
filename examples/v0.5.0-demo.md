# Demonstração v0.5.0

Gerado por `python scripts/demo_v05.py` (sem modelo). As candidatas são textos fixos escritos para a demonstração, tratados pelo engine como respostas de um provider; o caso de provider indisponível roda um comando que falha de verdade. Nada aqui é resultado de benchmark.

## Reescrita com plano e validação

*rascunho com fórmulas; o plano manda cortar a fórmula e manter os valores.*

**Original**

```text
É importante destacar que o deploy da versão 2.4 não deve ser feito antes das 18h de sexta, porque o banco estará em manutenção.
```

**Análise**: gênero `technical`, registro `technical`; achados editoriais: 1 fortes, 0 fracos (decisão do detector: `edit`).

**Plano**: decisão `edit`, escopo `local`.

**Candidata (fixa, escrita para a demonstração)**

```text
O deploy da versão 2.4 não deve ser feito antes das 18h de sexta, porque o banco estará em manutenção.
```

**Resultado**: desfecho `needs_judgment`; gate `no_deterministic_issues`; achados do gate: `metadiscourse_changed`.

**Texto entregue**

```text
O deploy da versão 2.4 não deve ser feito antes das 18h de sexta, porque o banco estará em manutenção.
```

**Análise**: gênero `email`, registro `professional-natural`; achados editoriais: 0 fortes, 0 fracos (decisão do detector: `no_change_candidate`).
